# Consultas de CASA VIP 0.5.0

Se conservan los contratos comerciales de API_0_4_0.md. Los parámetros nuevos son opcionales y no alteran los permisos del servidor. Si se omite month, la API consulta todos los períodos; la interfaz establece el mes actual.

| Consulta GET | Parámetros |
|---|---|
| /api/clients | q, month=AAAA-MM, category=POTENCIAL o SEPARACION o VENTA |
| /api/reservations | month=AAAA-MM, state=ACTIVA o CONFIRMADA o LIBERADA |
| /api/admin/history | entity=CLIENTE u OPERACION o CATALOGO o USUARIO, month=AAAA-MM, user=identificador |
| /api/admin/history/users | Usuarios que tienen auditoría, incluso retirados |

Omitir category, state, entity o user consulta todos los valores autorizados de esa dimensión. Formatos de mes y categorías inválidos devuelven HTTP 400. Cliente y operación siguen restringidos al asesor autenticado, salvo los roles de gestión. Historial y su lista de usuarios requieren responsable comercial o administrador.

Clientes incluye fecha_registro y operaciones autorizadas. Operaciones devuelve columnas de lista y fechas de venta/liberación; sus instantáneas y documentos se consultan en /api/operations/{id}. Auditoría conserva anterior y actual como datos estructurados para producir la comparación visual. Nunca se deben mostrar estos campos como JSON al usuario final.

Ejemplos: /api/clients?month=2026-10&category=POTENCIAL y /api/admin/history?month=2026-09&entity=OPERACION&user=1. El período se calcula en America/Lima y excluye el comienzo del mes siguiente. Los detalles temporales de cada entidad figuran en NOVEDADES_0_5_0.md.
